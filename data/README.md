# data/

Сюда кладутся исходные файлы, не распространяемые вместе с репозиторием:

- `train.parquet` — дневные логи активности пользователей (18 колонок:
  `event_date`, `user_id`, поисковые/каталожные/корзинные/заказные счётчики и GMV).
  Объём: 250 000 пользователей, ~30 млн строк, период 2025-01-01 .. 2026-02-13.
- `sample_submit.csv` — шаблон сабмита с двумя колонками `user_id, predict`
  (250 000 строк). Используется как список оцениваемых пользователей
  и как наивный бейзлайн организаторов (`predict == GMV за последние 30 дней`).

Запуск всех скриптов предполагается из корня репозитория, поэтому пути в коде
указаны как `data/train.parquet` и `data/sample_submit.csv`.

Файлы `*.parquet` и `*.csv` в этом каталоге игнорируются Git (см. `.gitignore`).
