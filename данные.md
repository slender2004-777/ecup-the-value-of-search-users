# Данные

## train.parquet
**Размер:** 180.1 MB  
**Содержимое:** исторические данные пользовательского поведения за период с 2025-01-01 по 2026-02-13.

### Поля
| Поле | Описание |
|------|----------|
| `event_date` | Дата события (с 2025-01-01 по 2026-02-13) |
| `user_id` | Идентификатор пользователя |
| `search` | Флаг пользования Поиском (0 или 1) |
| `cat` | Флаг пользования Каталогом (0 или 1) |
| `has_search_to_cart` | Флаг переноса товара в корзину при пользовании Поиском (0 или 1) |
| `has_search_to_order` | Флаг покупки товара при пользовании Поиском (0 или 1) |
| `has_cat_to_cart` | Флаг переноса товара в корзину при пользовании Каталогом (0 или 1) |
| `has_cat_to_order` | Флаг покупки товара при пользовании Каталогом (0 или 1) |
| `search_to_cart` | Число добавленных в корзину товаров при пользовании Поиском |
| `search_to_order` | Число добавленных в корзину товаров при пользовании Поиском (в исходном описании возможно опечатка) |
| `cat_to_cart` | Число добавленных в корзину товаров при пользовании Каталогом |
| `cat_to_order` | Число добавленных в корзину товаров при пользовании Каталогом |
| `gmv_search` | Суммарная стоимость купленных товаров при пользовании Поиском |
| `gmv_cat` | Суммарная стоимость купленных товаров при пользовании Каталогом |
| `to_cart` | Суммарное число добавленных в корзину товаров |
| `to_order` | Суммарное число добавленных в корзину товаров (вероятно, опечатка: должно быть "заказанных") |
| `gmv` | Суммарная стоимость купленных товаров |
| `searches` | Суммарное число поисковых запросов |

> **Примечание:** В исходном файле присутствуют дублирующиеся строки и возможные опечатки (например, `search_to_order` описан как «при пользовании Каталогом», что противоречит названию). Используйте данные с учётом этих нюансов.
